# ☕ Coffee Shop Sales Performance & Transaction Analytics

## 📌 Project Overview

This project analyzes coffee shop sales and customer transaction data using **Microsoft Excel**. The main objective is to understand sales performance, product demand, store performance, and monthly revenue trends from January to June 2023.

The project includes data cleaning, Excel formulas, PivotTables, PivotCharts, KPI cards, and an interactive dashboard to generate useful business insights.

## 🎯 Project Objectives

- Clean and prepare the raw dataset for analysis.
- Calculate total revenue and analyze sales performance.
- Compare revenue across different store locations.
- Identify the best-performing product categories and product types.
- Analyze monthly revenue trends.
- Create an interactive Excel dashboard.
- Provide business insights and recommendations based on the analysis.

## 📊 Dataset Overview

- **Dataset Name:** Coffee Shop Sales
- **Data Source:** Kaggle — Ahmed Mohamed's Coffee Shop Sales dataset
- **Analysis Period:** January–June 2023
- **Original Records:** 150,765
- **Records After Cleaning:** 149,110
- **Number of Columns:** 11
- **Tool Used:** Microsoft Excel

### Dataset Columns

The dataset contains the following columns:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail

## 🧹 Data Cleaning and Transformation

The following data cleaning steps were performed using Microsoft Excel:

- **Missing Values:** Checked all columns for missing values.
- **Duplicate Records:** Identified and removed duplicate records.
- **Data Type Conversion:** Checked and corrected data types for dates, times, numbers, and text.
- **Invalid Value Checking:** Reviewed important fields for invalid or unexpected values.
- **Text Standardization:** Corrected inconsistent text, including changing `lower manhattan` to `Lower Manhattan` and `cofee` to `Coffee`.

These steps helped improve data consistency and prepare the dataset for analysis.

## 🧮 Excel Formulas and Functions

The following Excel functions were used in the project:

| Function | Purpose |
|---|---|
| SUM | Calculated total revenue. |
| SUMIF | Calculated revenue based on a single condition. |
| SUMIFS | Calculated revenue based on multiple conditions. |
| AVERAGE | Calculated average revenue per transaction record. |
| COUNT | Counted numeric transaction IDs. |
| COUNTIF | Counted records matching a specific condition. |
| IF | Classified transactions based on quantity. |
| IFS | Classified transactions into revenue levels. |
| XLOOKUP | Retrieved product details using Product ID. |
| EOMONTH | Calculated month-end dates for monthly analysis. |
| RANK.EQ | Ranked store locations based on revenue. |

### Revenue Calculation

A new column named `Total_Revenue` was created using the following formula:

`=Transaction_qty*Unit_price`

This calculation was used to analyze total revenue across stores, categories, and products.

## 📈 PivotTables and PivotCharts

Four main analyses were performed using PivotTables and PivotCharts.

### 1. Revenue by Store Location
Compared total revenue across Astoria, Hell's Kitchen, and Lower Manhattan.

### 2. Revenue Contribution by Product Category
Analyzed the revenue generated by different product categories, including Coffee and Tea.

### 3. Quantity Sold by Product Type
Compared the quantity sold across product types to understand product demand.

### 4. Monthly Revenue Trends
Analyzed revenue changes from January to June 2023.

## 📊 Interactive Dashboard

An interactive dashboard was developed in Microsoft Excel to present the main results in one worksheet.

### Key Performance Indicators (KPIs)

The dashboard includes four KPI cards:

- Total Revenue
- Total Quantity Sold
- Total Transactions
- Average Revenue per Transaction

### Interactive Features

The dashboard includes:

- **Store Location Slicer:** Filters the analysis by store.
- **Product Category Slicer:** Filters the analysis by product category.
- **Product Type Slicer:** Filters the analysis by product type.
- **Transaction Date Timeline:** Filters the analysis by month or date range.

These features allow users to explore sales performance from different perspectives.

## 💡 Key Findings

### 1. Overall Sales Performance
The project analysis reports total revenue of approximately **698,780.73** from January to June 2023.

### 2. Store Performance
- **Hell's Kitchen:** 236,487.92
- **Astoria:** 232,243.91
- **Lower Manhattan:** 230,048.90

Hell's Kitchen generated the highest revenue among the three store locations.

### 3. Product Category Performance
- **Coffee Revenue:** 269,945.45
- **Tea Revenue:** 196,398.35

Coffee was the highest revenue-generating product category, contributing approximately 38.6% of total revenue.

### 4. Product Demand
Brewed Chai Tea recorded the highest quantity among the product types highlighted in the analysis, with **26,248 units sold**.

### 5. Monthly Revenue Trends
- **Lowest Monthly Revenue:** February — 76,145.19
- **Highest Monthly Revenue:** June — 166,485.88

Revenue increased each month from March through June 2023.

*Note: The dataset shows sales patterns but does not explain the reasons behind monthly revenue changes.*

## 📌 Business Recommendations

- **Investigate Sales Decline:** Compare February sales across stores and product categories to identify areas with lower revenue.
- **Study Sales Growth:** Examine April-to-May sales to identify which stores and products contributed most to the increase.
- **Plan Product Stock:** Use historical sales quantities to plan stock levels for popular products.
- **Improve Product Planning:** Review product category performance to identify opportunities for improvement.
- **Track Future Performance:** Set monthly sales targets and compare actual results against them.
- **Maintain the Dashboard:** Update the dashboard regularly when new transaction data becomes available.
